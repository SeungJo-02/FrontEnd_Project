# 도서 응답에 장르 필드 추가 요청

## 무엇을 원하나

책을 볼 때 그 책이 어떤 장르인지 화면에 보여주고 싶다. 특히 **사용자가 온보딩에서 직접 고른
장르와 같은 이름**이어야 한다. 자기가 "소설"을 골랐는데 책에는 "한국소설"이나
"국내도서>소설/시/희곡"이 뜨면 고른 것과 이어지지 않는다.

## 지금 상태

| 응답                                             | 장르 필드                     | 비고                  |
| ------------------------------------------------ | ----------------------------- | --------------------- |
| `GET /api/v1/books/search` → `BookSummary`       | ❌ 없음                       | 검색 결과에 표시 불가 |
| `GET /api/v1/books/{bookId}` → `BookDetail`      | ❌ 없음                       | 도서 상세에 표시 불가 |
| `GET /api/v1/books/isbn/{isbn13}` → `BookDetail` | ❌ 없음                       | 〃                    |
| 피드 응답 → `FeedReviewBook`                     | ✅ `category: string \| null` | 형식이 아래 문제 참고 |

피드에만 `category`가 있다. 프론트는 이 값을 감상 카드에 배지로 표시하도록 이미 반영해 뒀다
(`src/components/common/ReviewCard.tsx`). 나머지 화면은 필드가 없어 손을 댈 수 없다.

## 문제: 형식이 온보딩 장르와 다르다

책 데이터는 알라딘에서 오고, 알라딘 카테고리는 계층 경로 문자열이다.

```
국내도서>소설/시/희곡>한국소설>2000년대 이후 한국소설
```

반면 온보딩에서 고르는 장르는 `GET /api/v1/genres`가 주는 목록이다.

```json
{ "genreId": 3, "name": "소설" }
```

이 둘을 잇는 매핑이 없으면, 장르 필드를 추가해도 사용자가 고른 것과 연결되지 않는다.
단순히 알라딘 값을 그대로 흘려보내는 건 원하는 결과가 아니다.

## 요청 사항

### 1. 알라딘 카테고리 → 앱 장르 매핑

책을 저장할 때(`findOrCreateBook`) 알라딘 `categoryName`을 앱의 장르 체계
(`/api/v1/genres`와 같은 목록)로 매핑해 함께 보관한다. 매핑되지 않는 책은 `null`로 둔다.

### 2. 도서 응답에 `genre` 추가

`BookSummary`(검색 결과)와 `BookDetail`(도서 상세, ISBN 조회) 양쪽에 추가한다.

```jsonc
{
  "bookId": 904,
  "title": "달러구트 꿈 백화점",
  "author": "이미예",
  // ... 기존 필드
  "genre": { "genreId": 3, "name": "소설" }, // null 허용
}
```

- 타입: `{ genreId: number, name: string } | null`
- `genreId`를 함께 주면 장르 칩을 눌러 같은 장르를 탐색하는 흐름으로 확장할 수 있다.
  이름만 주면 문자열 비교에 기대야 하므로 id를 함께 주는 편이 낫다.

### 3. 피드 `category`도 같은 형식으로 통일 (선택)

피드의 `FeedReviewBook.category`는 지금 문자열 하나다. 위 `genre` 객체와 형식이 달라
프론트가 두 갈래로 다뤄야 한다. 통합 피드 엔드포인트를 새로 만드는 김에
(`docs/통합_피드_API_명세.md`) 같은 `genre` 객체로 맞춰주면 좋다.

기존 `category` 필드는 바로 지우지 말고 한동안 함께 내려주면 프론트가 안전하게 옮겨갈 수 있다.

## 반영되면 생기는 것

- **도서 검색 결과**: 제목·저자·출판사 아래 장르 표시 → 원하는 장르 책을 눈으로 거를 수 있다
- **도서 상세**: 책 정보에 장르 표시
- **감상 카드**: 지금은 피드 응답에만 의존하는 배지를 모든 화면에서 일관되게 표시
- **빈 피드 첫 화면** (`src/components/feed/EmptyFeedGuide.tsx`): 지금은 장르 **이름을 검색어로**
  넣는 어림짐작으로 책을 찾는다. `genreId`로 거를 수 있게 되면 진짜 장르 추천이 된다.
